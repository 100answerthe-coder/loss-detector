# 손실 감지기

키움증권 계좌의 **당일 실현손익**을 지켜보다가, 정해 둔 손실 한도에 가까워지거나 도달하면 화면 팝업·소리로 알려 주는 윈도우용 프로그램입니다.

- 조회 전용: 잔고·실현손익·체결 내역을 **조회만** 하며, **주문 기능은 없습니다.**
- 키움증권의 공식 프로그램이 아닙니다.

## 다운로드
오른쪽 **Releases**에서 최신 버전의 `zip` 파일을 받으세요.

## 실행 방법
1. 받은 zip 파일을 **압축 풀기** (zip 안에서 바로 실행하지 마세요)
2. 폴더 안의 실행 파일(exe)을 더블클릭
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
4. 프로그램의 **사용법** 탭을 따라 키움 OpenAPI 키를 넣고 **감시 시작**

## 주의
- 키는 각자 키움 OpenAPI에서 **실전투자용**으로 직접 발급받으세요. 키를 다른 사람과 공유하지 마세요.
- 키는 내 PC의 윈도우 자격 증명 관리자에만 저장되며, 다른 곳으로 보내지 않습니다.
- 참고용 알림 도구입니다. 투자 판단과 손실의 책임은 사용자 본인에게 있습니다.
